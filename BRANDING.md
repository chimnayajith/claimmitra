# ClaimMitra brand assets

This folder contains the standalone brand assets based on the approved reference direction.

## Files
- `assets/branding/claimmitra_icon.svg` — transparent icon mark; no background tile.
- `assets/branding/claimmitra_logo.svg` — horizontal logo lockup with wordmark and tagline.
- `assets/branding/claimmitra_icon.png` — 1024px transparent PNG for app/icon workflows.
- `assets/branding/claimmitra.png` — 1000px wide transparent PNG of the horizontal logo.
- `assets/branding/claimmitra.ico` — multi-resolution Windows icon generated from the standalone mark. Note: Windows icons need a square canvas; the icon is placed on transparent background, not a rounded colored tile.

## Palette
- Navy: `#0F2A56`
- Blue: `#2563EB`
- Orange: `#F59E0B`
- Neutral: `#E5E7EB`
- Secondary text: `#64748B`

## Typography
Use Inter for UI text. The SVG wordmark uses Inter with a generic sans-serif fallback. Bundle the Inter font files in the app separately if the application must render the typeface consistently offline.
